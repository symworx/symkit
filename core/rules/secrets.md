# Secrets

- Never commit credentials, tokens, private keys, or `.env` files.
- Never paste secrets into chat logs, commit messages, or issue text.
- Prefer environment variables or a local untracked file documented in README.
- If a secret appears in the working tree, stop and tell the human to rotate it.
