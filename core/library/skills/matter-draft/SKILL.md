# Matter draft

One artifact. The human names which: chronology, memo section, letter,
request list, or cite table.

## Steps

1. Read the brief, `docs/matter/`, and the `record/` entries the brief names.
2. Use only those files and authorities the repo holds.
3. Write the artifact at the output path, usually under `drafts/`.
4. Put **Draft for attorney review** at the top. See `not-counsel.md`.
5. Where a fact or an authority is missing, leave a blank and list it.

## Do not

- Add a legal conclusion that `docs/matter/` does not already state.
- File, sign, or fill a blank with a guess.
- Rewrite the matter file.

## Output

- The artifact at the output path
- Blanks left open, with the file that failed to support them
- Open questions for the session that owns the legal position
