# Session plan

One session. Source: `docs/program/` and recent `docs/notes/`.

## Steps

1. Read the written program for this day/week and any stated constraints.
2. List what is already specified (exercises, intensities, tests). Leave
   blanks as blanks.
3. Add coaching cues that follow from those movements (mechanics + intent).
4. Note physiology only when it changes the session (e.g. stated heavy
   lower + stated interval day → call the recovery conflict; do not invent
   a fix).
5. Stop on pain or red-flag language in the notes (`no-clinical.md`).

## Do not

- Invent kg, %, RPE, or rest if the program does not have them.
- Stack a second session “because they can handle it”.

## Output

- Date / slot (from the program, or “unspecified”)
- Blocks (warm-up, main, accessory, test) using only written work
- Open questions for the human coach
