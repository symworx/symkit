# Record index

An index of the documents the brief names. Not a chronology with a theory.

## Steps

1. Read the brief and open each document it names.
2. For each one, record the id, the path, the title as printed, and the
   date only if the document states it.
3. List brief items you could not open.
4. Write the index at the output path, usually under `record/`.
5. Leave the source documents unchanged.

## Do not

- Say what a document proves, breaches, or waives.
- Invent a date, a party, or a page that is not on the document.
- Describe a document that is not in the repo.

## Output

- What you were asked to index
- The index: id, path, title as printed, date as printed or "unspecified"
- Missing items
- Open questions for the session
