# Brand voice

Apply written voice. Source: `docs/brand/` and `brand.md`.

## Steps

1. Read `docs/brand/` (voice, forbidden phrases, examples).
2. If that tree is empty, ask whether to draft a **starter** page there.
   Do not invent a palette or logo.
3. For existing copy: list mismatches (word, claim, or tone) with a rewrite.
4. For new copy: write in that voice; keep claims inside product truth.

## Do not

- Mint a brand kit “to get started” (colors, type, tagline) unasked.
- Override names already used in the repo.
- Generate pixels — use `asset-brief`.

## Output

- Voice rules used (or “none on disk — asked”)
- Edits or draft copy
- Open brand questions
