# Physio explain

Mechanisms, not a chart of invented numbers. Pair with `check-citations`
when you cite.

## Steps

1. Name the question and the written context (which session or test).
2. Explain the mechanism at the level asked (cellular vs session vs block).
3. Connect to mechanics when it matters (e.g. stated heavy eccentric +
   stated next-day speed).
4. Cite sources you actually have; if you do not have one, say so.
5. Stop short of clinical interpretation.

## Do not

- Invent VO2, lactate, or hormone values for this athlete.
- Recommend supplements, drugs, or labs.
- Pretend a textbook average is this person’s data.

## Output

- Mechanism in plain language
- Link to the written program (or “no program context”)
- Sources used / not available
- What would require a clinician
