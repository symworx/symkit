# Punch-up

A tighter pass on a bit that already exists.

## Steps

1. Read the bit and `docs/room/`.
2. Cut words that do not change the laugh.
3. Keep the form, the premise, and any limit the room file states.
4. Write the tightened bit at the output path. Leave the source file unless the human said to overwrite it.

## Do not

- Add a new premise or a new form.
- Turn a dad joke into another kind of bit, or the reverse, unless the human asked.
- Invent a laugh the notes do not record.

## Output

- What you cut, in a line or two
- The tightened bit
- Open questions for the comedian
