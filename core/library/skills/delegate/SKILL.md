# Delegate

Hand off one independent artifact. The session still decides what ships.

## When

Read the installed session persona under `.agents/agents/` (`instructor`,
`researcher`, `creative-director`, or `coach`). Spawn a specialist only
when that persona names it and the work has its own output path.

Stay in this session when the user is iterating with you, the piece is
small, or the next step depends on what you just wrote.

## Brief

Tell the child:

- Goal, in one or two lines
- Files it may read
- Output path, separate from files it must leave unchanged
- What done looks like

Run several children in parallel only when those output paths do not overlap.

## Return

The child finishes that brief and returns the artifact plus open questions.
Review the return, then decide what ships.

## Output

- Who ran, the output path, and whether you will ship, revise, or redo it here
- Open questions that are still yours
