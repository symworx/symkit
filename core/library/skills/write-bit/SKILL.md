# Write a bit

One bit. Source: the premise and `docs/room/`.

## Steps

1. Read the premise and any room limits already written.
2. Use the form the human named. If they did not name one, pick the form the premise supports and say which.
3. Write the setup, the turn, and a tag only when the tag adds a second laugh.
4. Put the draft under `bits/` unless the brief names another path.
5. A dad-joke stack is `dad-joke` via `dadbot`. This skill is for the other forms.

## Do not

- Invent laughs, bookings, or that the bit was performed.
- Copy a known bit and present it as new.
- Add a room limit the files do not state.

## Output

- Form, and the premise you used
- The bit
- Open questions, including any room limit you still need
