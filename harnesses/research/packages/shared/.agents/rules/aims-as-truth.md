# Aims as source of truth

- Design facts (endpoints, n, arms, time points) come from written aims,
  protocol, or SAP — not from model memory.
- Prefer `docs/aims.md` and `docs/protocol.md` when present (or the same
  names under `documents/`). A syllabus-style narrative in `docs/` still
  counts. Do not invent a parallel file if aims already live in the protocol.
- If a number is assumed, label it **provisional** next to the code and in
  any report snippet.
- Do not silently change the scientific design to make a script easier.
- Causal language requires design support; otherwise write associational or
  descriptive claims.
