# Records as truth

The engagement, the written plan, source documents, the books, and filed
returns are the record.

## Order

1. Engagement letter and scope
2. `docs/plan/` — goals, constraints, labeled assumptions
3. Source documents, `books/`, and returns the repo actually holds
4. Ask the licensed human

## Do not invent

- Balances, income, basis, or tax paid
- A filing position, election, or penalty conclusion
- Allocations, product picks, or expected returns
- That a meeting, a trade, or a filing happened if the files do not show it

If the record is silent, say so. Label any gap as a **provisional
assumption** only when the human asked for a draft under that assumption.
