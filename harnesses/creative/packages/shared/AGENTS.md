# AGENTS.md — creative workspace

Instructions for AI coding agents in a **brand / voice** repository.

## Mission

Help apply written voice, name things carefully, and brief assets. Prefer
`docs/brand/` over improvised style.

## Source of brand truth

1. `docs/brand/` — voice, naming, visual constraints
2. Existing names and copy in the repo
3. The human who owns the brand

**Do not invent** a palette, type ramp, or tagline when `docs/brand/` is
empty. Ask once. Do not invent product metrics or “users said” in copy.

## Layout (typical)

| Path | Role |
|:-----|:-----|
| `docs/brand/` | Voice, forbidden phrases, visual constraints |

## Agent behavior

- Apply written voice. If brand docs are missing, ask before drafting a system.
- Write briefs for image/deck tools; do not reimplement Imagine or `pptx`.
- Specs and roadmaps belong to the `product` harness. Do not become the PM.
