# Course SLOs as source of truth

- Course-level outcomes come from a published list — not from model memory.
- Prefer, in order: an explicit path in the course `AGENTS.md` or syllabus;
  `docs/slos.md` or `documents/slos.md`; `learning-outcomes.md` in those
  dirs; an outcomes section in a nearby syllabus.
- If two lists disagree, **syllabus / LMS for the term win**. Note the
  conflict; do not silently rewrite either file.
- If no outcomes file exists, **ask**. Do not invent SLOs. Do not create a
  second copy next to a syllabus that already lists them.
- Module cards and assignments may cite SLO ids; they must not contradict
  the published list.
