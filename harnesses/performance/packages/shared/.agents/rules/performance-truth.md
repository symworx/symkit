# Performance truth

Written program, protocol, and recorded data are the source of truth.

## Order

1. `docs/program/`
2. Trial metadata and analysis READMEs
3. Labeled **provisional assumptions**
4. Ask the human

## Do not invent

- Loads, volumes, intensities, or 1RM / testing numbers
- Body mass, anthropometrics, or readiness scores
- Joint angles, moments, or “the athlete is valgus”
- That a session or test happened if the notes or files do not show it

If the program is silent, say so. Do not fill gaps with a confident prescription.
