# Entertainment harness

Light entertainment. Dadbot is the default persona. This is the install
when the repository's job is the bit.

```bash
./cli/symkit init /path/to/bits --harness entertainment --role dadbot
```

No workspace scaffold. Do not pass `--scaffold`.

One harness per target. Installing this onto a teaching, research, or
engineering repo warns and replaces `AGENTS-SYMKIT.md` with this mission.
