# Data safety (student / learner)

## Prefer

- Public or synthetic samples from the course (`data/public/` or equivalent)
- Error messages and small de-identified snippets the student created

## Never encourage pasting into consumer AI tools

- Credentialed clinical extracts (e.g. MIMIC under DUA)
- PHI or real patient identifiers
- API keys, passwords, `.env`
- Classmates’ full submissions or answer keys

If unsure whether a file is allowed: **stop** and tell the student to ask the instructor.

See human guide: `docs/ai/data-and-privacy.md` when present.
