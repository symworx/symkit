# Disclosing AI use

When the syllabus, LMS assignment, or project brief asks you to disclose AI use, be **brief and honest**.

## Default one-liner (often enough)

> Used [tool] for [purpose: e.g. debugging Lab 1 JSON parse error / outlining Path B / grammar pass]. I verified and can explain all submitted content.

## Slightly longer (projects)

```text
AI tools: ChatGPT (debug cohort merge); GitHub Copilot (boilerplate only).
Not used for: final interpretation paragraph; choosing inclusion criteria.
```

## What to include

| Include | Usually skip |
|:--|:--|
| Tool name(s) | Full chat logs (unless asked) |
| Purpose (debug, outline, grammar, ideas) | Marketing claims about the model |
| That you verified the result | Fake precision (“37 prompts”) |

## What not to do

- Disclose nothing when the course **requires** disclosure.  
- Claim “no AI” if a tool wrote substantial graded content.  
- Dump private data into the disclosure itself.  

## Course variation

Some courses use a LMS checkbox only. Others want a short paragraph in the project package. **Follow that course’s instructions.**

## Integrity

Disclosure does **not** make fabricated results or un-understood code acceptable. It only makes allowed assistance transparent.
